# vivid-cloud

Blender (Eevee) render jobs for the Doodle Got Noodles VIVID look on free GitHub Actions runners.

- `studio/lib`, `studio/sets`: the scene-building code.
- `studio/assets/kenney`: Kenney CC0 model packs (https://kenney.nl). The license is included in each pack.
- `.github/workflows/speedtest.yml`: renders a few frames and times them.

Only silent frames are rendered here. Voice, music and final edits are added offline.
